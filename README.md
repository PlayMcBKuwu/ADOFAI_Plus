# ADOFAI Better Judgment Lite (更好的判定 Lite)

专为节奏游戏《**冰与火之舞**》（*A Dance of Fire and Ice*, 简称 ADOFAI）打造的 **纯净绿色版** Unity Mod Manager (UMM) 判定分析模组。

本版本为 **更好的判定 (Better Judgment)** 的 **Lite 纯净分支**：**完全去除了任何判定窗口篡改（移动判定/自定判定）、自动播放+、不死模式及强制自动播放**，仅保留原版 PC 判定下的微观判定指示器全家桶与实用视觉增强，绿色安全，无需免责弹窗即可即开即用。

---

## 📖 核心功能

1. **判定指示器全家桶 (Hit Indicator Family)**
   - **原生精确参数梯级重测 (Strict → Normal → Lenient)**：
     - 实时捕获游戏底层 `GetHitMarginInSec` / `GetHitMarginInDeg` 的未截断精确参数，完美适配倍速试炼、变速砖块与 **练习模式降速 (如 0.9x)**；
     - **严判成立优先守卫**：只要敲击在严格判定下已成立（或在严格难度下打出及格），绝不误报标判/宽判。
   - **判定指示器**：打出 Counted 及格时，标判成立施加 **灰色描边**，仅宽判成立施加 **绿色描边**，并同步至底部判定条打点（`ErrorMeterTick`）。
   - **判定指示器+**：将文字替换为「**标判！**」与「**宽判！**」（精简模式 `NOR` / `LEN`）。
   - **另类判定指示器+**：支持正负符号前缀（`-宽判！` 太快 / `+标判！` 太慢）与字符前缀（`L太快！` / `N太慢！`），并兼容毫秒误差模式（`-60msN` / `+60msL`）。
   - **双感叹号失误指示器**：支持在空敲或失误断连（`!!`）时提示跨难度保命区间（如在严判/标判下失误时提示 `--标判！！` 或 `++宽判！！`）。
   - **结算详细结果统计**：在开启「显示详细结果」且本局打出过标判/宽判时，追加显示 `<color=#aaaaaa>标判: X</color>     <color=#26ff59>宽判: Y</color>`。
2. **强制启用原版判定选择栏**
   - 在低 BPM 关卡中也可常驻解锁原版「宽松 / 标准 / 严格」切换，并自动隐去低 BPM（< 200 BPM）关卡中多余的「关卡速度较快」提示。
3. **隐藏星球判定圈**
   - 一键隐藏围绕旋转星球的虚线轨道圈（`scrRing.line`）。
4. **全 14 种原版语言支持**
   - 默认自动跟随游戏语言（`RDString.language`），亦支持手动切换。
