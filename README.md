专为节奏游戏《**冰与火之舞**》（*A Dance of Fire and Ice*, 简称 ADOFAI）打造的 100% 纯绿色、比赛合规（Tournament-Legal / Fair-Play）功能补全与视觉本地化增强模组。

本模组专注于**补全游戏原生缺失的视觉反馈与多语言体验**，在完全不干预任何底层判定时间与物理机制的前提下，为追求公平竞赛与原版手感的玩家提供更加完善的游戏体验。

---

## 🍃 纯绿色与比赛合规保证 (Fair-Play Guarantee)
- **零改判**：绝不修改游戏的任何判定窗口（毫秒 / 角度）、及格线或容错时间，100% 保持官方原版判定标准。
- **零作弊**：彻底剥离任何自动播放、脚本模拟、锁血不死、加速减速或外挂逻辑，无需免责声明弹窗。
- **天梯与赛事完全合规**：所有通关记录与分数 100% 原版原生，完全符合各类官方及社区赛事、段位认证审核标准。

---

## 📖 核心功能概览

### 1. 地道多语言本地化与排版补全
原版游戏在日语等部分语言下直接沿用了英语判定词（如 Early / Late），且日文字体在部分分辨率下较为纤细。本模组补全了地道的本土化文本与排版表现：
- **地道日语判定文本**：提供符合日语母语节奏游戏习惯的地道判定文本（早め！ / 遅め！ / 早すぎ！ / 遅すぎ！ 等），完整保留感叹号等标志性语义符号，与中文、韩语及英语体系风格高度统一。
- **中文字体平滑替换**：内置「日语界面下使用中文字体」开关（默认开启），在日语环境下平滑替换为更加饱满清晰的中文字体，大幅提升可读性。

### 2. 多层级判定指示器与视觉反馈 (反馈补全)
原生游戏在严格判定下仅提示是否及格，缺乏更细腻的击打区间反馈。本模组在后台进行非侵入式判定比对，补齐了完整的层级化判定指示体系：
- **标判！与宽判！重测指示**：在严格或标准判定下游玩时，若命中落在及格区间，后台实时根据各判定标准重新计算，精准提示该音符落入「标判！」还是「宽判！」。
- **另类指示器+**：支持符号指示（`-标判！` / `-宽判！！` 太快 / `标判！+` / `宽判！！+` 太慢）或方向前缀（`L-太快！` / `N-太慢！`），直观呈现击打偏早或偏晚。
- **失误判定区间比对**：在打出「太快！！」或「太慢！！」时，亦可比对是否落入宽松或标准窗口，便于高难关卡复盘。
- **文字边框与轨道染色独立切换**：打出标判/宽判时支持将浮动文字边框与轨道对应染为灰色或绿色，均配备独立设置开关。

### 3. BPM 提示智能自动隐藏
- 智能计算关卡综合实际 BPM（兼容加速轨、变速事件与练习模式倍速乘算）。
- 自动隐藏非必要的难度建议提示，保持游戏画面干净整洁。

## 📦 编译与安装

1. **手动编译**：在项目根目录运行 `powershell -ExecutionPolicy Bypass -File build.ps1`，脚本会自动寻找本地 ADOFAI 安装目录并一键编译部署。
2. **自动化构建**：本项目配备 GitHub Actions CI 工作流，推送即可自动打包直出完整的 Zip 模组包并发布至 GitHub Releases。
3. **安装方式**：将 Release 中的 Zip 包拖入 Unity Mod Manager 界面，或解压到 `[游戏目录]/Mods/ADOFAIPlus/` 即可。
