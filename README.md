专为节奏游戏《**冰与火之舞**》（*A Dance of Fire and Ice*, 简称 ADOFAI）打造的 100% 纯绿色、比赛合规（Tournament-Legal / Fair-Play）视觉与本地化增强模组。

---

## 🍃 纯绿色游戏保证 (Fair-Play Guarantee)
- **零改判**：绝不修改游戏的任何判定窗口（毫秒 / 角度）、及格线或容错时间。
- **零作弊**：不含任何自动播放、拟人脚本、锁血不死、加速减速或外挂逻辑。
- **天梯与赛事合规**：所有通关记录与分数 100% 原汁原味，符合各类第三方赛事与段位审核标准。

---

## 📖 核心功能概览

### 1. 更好的日语本地化与字体修复
- **地道日语判定文本**：针对原版日语直接复用英文判定词的问题，提供自然贴切的日语本地化（如「少し早い！ / 少し遅い！」与韩语、中文风格高度统一；Ready / Go 自然本地化）。
- **中文字体平滑替换**：原版日文字体在部分分辨率下纤细且显示欠佳，模组内置「日语界面下使用中文字体」开关（默认开启），让日文排版清晰美观。

### 2. 判定指示器 (Hit Indicator)
- **标判！与宽判！提示**：在严格或标准判定下游玩时，及格击打会由模组在后台进行比对计算，并在浮动文字与误击量计上提示该音符是否落入标准判定或宽松判定窗口。
- **另类指示器+**：提供正负符号前缀（`-宽判！` 太快 / `+标判！` 太慢）或方向前缀（`L-太快！` / `N-太慢！`）。
- **失误判定指示器**：即使在「太快！！」与「太慢！！」时也能显示是否落在宽判/标判窗口。
- **边框与轨道染色独立切换**：打出标判/宽判时支持将浮动文字边框与轨道对应染为灰色或绿色，均配备独立设置开关。

### 3. BPM 提示智能自动隐藏
- 智能计算关卡综合实际 BPM（兼容加速轨、变速事件与练习模式倍速乘算）。
- 自动隐藏非必要的难度建议提示，保持游戏画面干净整洁。
